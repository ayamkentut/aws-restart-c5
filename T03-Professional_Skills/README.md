# 📁 T03-Professional_Skills: Foundational Soft Skills (FSS)

This directory contains the complete curriculum of **Professional Soft Skills (Techno Functional Soft Skills - FSS)** for the **AWS re/Start** program. Every document has been converted from official PDF training guides into high-yield, structured Markdown study guides equipped with interactive checklists, behavioral interview frameworks, and practical cloud engineering templates.

---

## 🛡️ Project Standards
All documents in this directory comply with the repository standards set in [PROJECT_STANDARDS.md](file:///work/tmp/aws-cf/PROJECT_STANDARDS.md):
- Normalized naming: `T03-xxxx-[DESCRIPTOR].md` (no spaces, underscores only).
- Pure GitHub Flavored Markdown (GFM) without external notebook tags.
- Comprehensive coverage of slides, speaker notes, and discussion exercises.
